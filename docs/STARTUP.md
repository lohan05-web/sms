# Startup Guide

Development
- npm run dev (backend only for now)

Build
- npm run build (builds shared + backend)
- npm run start (runs backend from dist)

Checks
- npm run typecheck
- npm run lint
- npm run lint:fix
- npm run format
- npm run format:check
- npm test

DB
- npm run db:up (docker mysql)
- npm run db:down
- npm run db:migrate
- npm run db:deploy
- npm run db:seed
- npm run db:studio
